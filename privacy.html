Privacy policy

Last updated 25 September 2026

Skewer is a school project for ICT 10. It is a static website with two browser tools: a SKU generator and a receipt generator. This page explains in plain terms what the site does with information.

Information we collect

None. The site has no accounts, no sign in, no contact form, and no server of its own. It sets no cookies and runs no analytics or advertising trackers.

What you type stays in your browser

Categories, product names, stock quantities, and menu selections are read by Python code running inside your browser through PyScript. The results are written back into the page on your own device. Nothing you enter is sent to us, stored by us, or kept after you close or refresh the page.

Third-party files this page loads

To display, the page requests files from the following providers:

  • GitHub Pages, which hosts the website.
  • PyScript, which runs the Python code in the browser.
  • Google Fonts, which serves the Inter typeface.

When your browser requests those files, the provider receives ordinary technical data such as your IP address, browser type, and the address of the file requested. Those providers handle that data under their own privacy policies.

Children's privacy

The site is made for classroom use and is not directed at collecting personal information from anyone, including children. Because no personal information is collected, no personal information is disclosed or sold.

Changes to this policy

If the project changes how it handles information, this page will be updated in the same repository as the code, so the current version is always the one published on the site.

Questions

Questions about this project can be left as an issue on the GitHub repository.
